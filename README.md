# Двое

Общее пространство для пары: задачи, календарь, хотелки, документы, планы, капсулы времени и тайные голосования.

Данные синхронизируются через сервер и Postgres — не нужно быть онлайн одновременно.

**Сайт:** [two-nine-khaki.vercel.app](https://two-nine-khaki.vercel.app)

---

## Возможности

| Раздел | Что внутри |
|--------|------------|
| **Задачи** | Общий список дел: взять себе, поставить партнёру, отметить выполненным |
| **Календарь** | События, сроки задач, дни рождения |
| **Хотелки** | Желания с ссылкой, ценой и картинкой — для себя или партнёра |
| **Документы** | Карточки и файлы (в виде data URL) |
| **Мы** | Планы и поездки, капсулы времени, голосования «за двоих» |

Синхронизация: опрос `/api/state` каждые ~8 секунд + сразу при возврате во вкладку. При конфликте побеждает более новая версия (устаревшая запись отклоняется с 409).

## Стек

- **TanStack Start** (React 19, Router, SSR)
- **Vite** + **Nitro** (деплой на Vercel)
- **Tailwind CSS v4** + Radix UI
- **Zustand** — клиентское состояние
- **Postgres** (Neon на Vercel) — общее хранилище
- **Kysely** + миграции при сборке

Авторизация (`better-auth`) в проекте есть, но сейчас **выключена**.

## Локальный запуск

```bash
npm install
npm run dev
```

Приложение: [http://localhost:8080](http://localhost:8080)

Без `DATABASE_URL` используется временная заглушка (данные не сохраняются между перезапусками). Для полноценной синхронизации локально укажи URL Postgres:

```bash
export DATABASE_URL="postgresql://..."
npm run dev
```

## Деплой на Vercel

Подробности — в [DEPLOY.md](./DEPLOY.md). Кратко:

1. Запушь код в GitHub.
2. В Vercel подключи **Neon** (Storage → Marketplace) **до** или после первого деплоя — нужна переменная `DATABASE_URL`.
3. Deploy. Миграции (`migrations/0001_app_state.sql`) применяются автоматически при `npm run build`.

**Важно:** не коммить папку `.vercel/output` — иначе Vercel зальёт старый бандл и не пересоберёт проект. Добавь `.vercel` в `.gitignore`.

```

```

## Заметки

- Интерфейс на русском.
- Один общий JSON-стейт в БД (одна строка) — подходит для двоих, не для публичного сервиса.
- Тайное голосование скрывает чужой выбор в UI до конца, но сами данные лежат на сервере — это вопрос доверия, а не криптографической приватности.
